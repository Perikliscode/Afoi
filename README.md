Concept and features:
 Diogee is an AI assistant which helps the user understand in seconds his health status
 about serious illnesses (In this case, specifically cancer). It's easy to use, because
 the cancer risk factors are ready to be given in the program, in a form and it requires
 no research for the user.

 AI makes a response based on the information the user put,
 which includes an approximate concern for cancer about the user, advice on how to lower
 the risk of cancer and it combines the last doctor appointment of the user and the 
 doctor visit standards to suggest when his next appointment should be. In the end it
 refers to a fact about cancer risk people often neglet, so the user will notice.
 
 The 'submit' button gives the AI the user's information from the form and moves the
 user to the response page. The 'Return to form' button moves the user to the initial page
 where he can repeat the process.)
